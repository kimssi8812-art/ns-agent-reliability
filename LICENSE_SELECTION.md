# License selection — applied to release candidate

Status: APPLIED_TO_PREPUBLICATION_CANDIDATE / NOT YET PUBLIC  
Effective: 2026-09-08

The previously recommended split is now applied to the release candidate:

- software/tests/schemas/executable examples: **Apache-2.0**;
- original narrative documentation and sanitized incident reports: **CC BY 4.0**;
- NS names/logos/distinctive brand assets: outside the open-license grant;
- third-party material: original upstream provenance controls.

Rationale: Apache-2.0 is permissive for infrastructure software and includes an explicit patent grant/termination framework. CC BY 4.0 permits broad reuse of original narrative material with attribution.

Canonical texts: `LICENSE` and `LICENSES/CC-BY-4.0.txt`. Scope: `LICENSE_POLICY.md`. Attribution/provenance: `NOTICE`, `THIRD_PARTY_NOTICES.md`, `TRADEMARKS.md`.

This license application does not mean the repository has been published. Public exposure is complete only after the approved GitHub remote is pushed and remotely verified.
